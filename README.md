# Glow Beauty Studio

Web stranica za [Glow Beauty Studio](https://www.instagram.com/gllow.beauty.studio/) – Bulevar Stup, Sarajevo.
Napravljena u [Astro](https://astro.build).

## Pokretanje

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # statični build u dist/
```

## Struktura

- `src/data/site.ts` – sav sadržaj (kontakt, usluge, radovi, cjenovnik)
- `src/components/` – sekcije stranice
- `src/styles/global.css` – boje, fontovi i zajednički stilovi (tokeni na vrhu fajla)
- `public/images/` – slike preuzete sa Instagram profila studija
